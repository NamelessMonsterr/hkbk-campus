Usage log admin

This view reads only this browser's local storage. There is no server and no hidden upload: data leaves the device only when someone clicks a download button here. See the evaluation page.

Privacy: the usage log is opt-in and stores outcomes only (what was answered or refused, category, confidence band, latency) - never question text. Ratings store the entry rated, never the question. Walk events store stops and dwell. The study kit stores only what its consent screen says. Anything can be deleted below, permanently.
