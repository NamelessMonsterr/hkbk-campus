HKBK Campus Walk
Open index.html through any static web server (for example: python3 -m http.server, then http://localhost:8000). It will not run from file:// because it loads frames_*.bin.
Controls: Start walk, then arrow buttons, arrow keys, scroll, swipe, or Walk autoplay. Restart returns to step 1; the small round map shows position.
Every image is a real campus-video still at 1600px (1 per second). Clip changes are hard cuts. Admin Block (F) has no footage yet.
360 upgrade: set "pano":"panos/<id>.jpg" on a stop in walk-data.js and a 360 button appears at that stop.
